# Geetaasameekshaa

A verse-level translation of Sri Bhagavad Geetaa in different languages.
Initial Kannada translation by Dr. Shatavadhaani Udupi Ramanatha Acharya.
Translations from Kannada to other languages by others.

## Transliteration

Transliteration between languages are primarily performed using [Aksharamukha Converter](https://www.aksharamukha.com/converter), supplemented with manual edits.

Verses are transliterated from Kannada to other languages. That is, Kannada is always the source. Transliteration to Latin ("romanized") uses [IAST scheme](https://www.aksharamukha.com/roman).

Aksharamukha transliteration results are post-processed to fix the following issues:

- Indent the verse text to match the source

### Transliteration options

Only the options mentioned hereunder are enabled for transliteration from Kannada. All other options for the target are disabled.

#### Devanagari

- Use Anusvara to nasalize (पञ्चगङ्गा → पंचगंगा)

Transliteration results are also post-processed to fix the following issues:

- In YAML keys, replace danda mark with period. E.g., the key 27.5 is transliterated as 27।5. Replacing the danda with a period restores the original key.

#### Tamil

- Use dandas

#### Telugu

- Use dandas

#### IAST Romanization

- Anusvara to nasal (gaṃgā → gaṅgā)
- Use dandas

Transliteration results are also post-processed to replace ASCII pipe marks with Devanagari danda marks.
